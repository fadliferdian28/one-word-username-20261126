This small program writes the account's own make.fun username, jackpoot, into entry.txt for the One Word, One Username, One Reward bounty. It checks that the word is a single valid word, writes it with one trailing newline, then re-reads the file and confirms the SHA-256 matches the expected digest before reporting success.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
